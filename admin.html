BSS SOLUTION (1978) ระบบจัดการเว็บไซต์
ยังตั้งค่าไม่ครบ

การแก้ไขจากเว็บจริงต้องตั้ง Environment Variables ใน Vercel ก่อน — ยังขาด:

ตั้งที่ Vercel → Project → Settings → Environment Variables แล้ว Redeploy หนึ่งครั้ง

กำลังแก้ไขเว็บจริง

เมื่อกดบันทึก ระบบจะบันทึกเข้า GitHub แล้ว Vercel จะ deploy ให้อัตโนมัติ — หน้าเว็บจริงจะอัปเดตในราว 1 นาที หลังบันทึก

เลือกหน้าที่ต้องการแก้ไข

กด “แก้ไขหน้านี้” เพื่อเปิดหน้าเว็บจริงในโหมดแก้ไข เมื่อกดบันทึกแล้ว ไฟล์ในเครื่องจะถูกอัปเดต จากนั้น git push เพื่อเผยแพร่

กด “แก้ไขหน้านี้” เพื่อเปิดหน้าเว็บจริงในโหมดแก้ไข คลิกที่ข้อความเพื่อพิมพ์แก้ คลิกที่รูปเพื่อเปลี่ยนรูป แล้วกดบันทึก

หน้าแรก index.html
แก้ไขหน้านี้ ดูหน้าเว็บ

แก้ไขหน้านี้ ดูหน้าเว็บ
บริการของเรา services.html
แก้ไขหน้านี้ ดูหน้าเว็บ
ติดต่อเรา contact.html
แก้ไขหน้านี้ ดูหน้าเว็บ
บทความ articles.html
แก้ไขหน้านี้ ดูหน้าเว็บ

วิธีใช้งาน

  1. กด แก้ไขหน้านี้ ระบบจะเปิดหน้าเว็บจริงพร้อมแถบเครื่องมือด้านบน
  2. คลิกที่ข้อความเพื่อพิมพ์แก้ได้เลย หรือคลิกที่รูปเพื่ออัปโหลดรูปใหม่
  3. กด บันทึกการแก้ไข (Publish) ที่แถบด้านบน
  4. ไฟล์หน้านั้นจะถูกเขียนทับทันที — รีเฟรชหน้าเว็บก็เห็นผลเลย

ระบบจะสำรองไฟล์เดิมไว้ในโฟลเดอร์ backups/ ทุกครั้งก่อนเขียนทับ หากแก้ผิดสามารถกู้คืนจากไฟล์สำรองได้

ทุกการบันทึกถูกเก็บเป็นประวัติใน GitHub — ถ้าแก้ผิดสามารถย้อนกลับได้ที่ ประวัติการแก้ไข
